Microsoft Arc Mouse デメリット｜買って後悔した口コミ5選

Amazonと楽天の合計1,620件超の口コミを横断して調べた。実際に集まった不満はこれだ。

手首が疲れる

折りたたんだ状態ではアーチが低くなり、デザイン優先の薄さが「手首への角度がつきにくい」問題に直結する。1〜2時間の軽作業なら問題ないが、丸一日デスクに向かう用途では手首が痛くなってくる。

スクロールホイールがない

これがArc Mouse最大のデメリットだ。タッチスクロールは使えるものの、エクセルの列移動や画像の細かい拡大縮小には向かない。慣れても不便さは残り、元のマウスに戻す人もいる。

クリック音が思ったより大きい

静かなカフェや会議室で使うと、クリック音が周囲に聞こえるレベルになる。図書館や深夜のオフィスで使う場面を想定しているなら、購入前に音の大きさを意識しておいた方がいい。サイレントクリック仕様ではない点は批判を集めやすい要素だ。

多機能派には物足りない

サイドボタンなし、DPI切替なし。8,000円超という価格帯を考えると、機能量に対して割高に感じる声が一定数ある。

ゲームや画像編集には向かない

高速トラッキングや精密操作を要求する用途には対応できない。この割り切りはMicrosoftが意図した設計であり、購入前に把握しておくべき前提だ。

Arc Mouse メリット・評判｜持ち歩きで光る理由

カバンに入れてもかさばらない

スナップで折りたたむとほぼフラットになり、PCバッグのスリムなポケットにも収まる。ポーチがいらなくなる携帯性が、リピート購入の一番の理由になっている。

Bluetoothの接続が速い

SurfaceやWindows機との相性が特に良く、スナップするとほぼ即座に認識される。ドングル不要なのでMacBookの薄型ポートでも邪魔にならない。

見た目がいい

金属的な質感と曲線デザインはカフェや会議室で浮かない。仕事道具感がなくてスッキリ見えるので、持ち物にこだわる層からの評価が高い。

単3電池1本で約6ヶ月

充電を忘れる心配がなく、電池切れは年に1〜2回程度。電池代は半年で100円程度で、ランニングコストはほぼゼロに近い。

上面全体がクリックになる設計

左右の境界が曖昧な一枚面なので、どの位置を押しても誤操作が起きにくい。持ち方が毎回微妙にズレる人には合っている構造だ。

アーチが手のひらにフィットして短時間なら疲れない

カフェで2〜3時間使う分には問題ない。あくまで短時間・軽作業が前提だが、折りたたんでポケットに入れて、スナップで即接続できる利便性とセットで効いてくる。

Microsoft Arc Mouseを買って後悔する人

デスクで長時間使おうとした人

持ち歩き設計のマウスを固定デスクのメイン機器にするのは用途の逆用だ。手首への負担は口コミでも一貫して指摘されており、8時間以上の連続使用には向かない。

スクロールホイール操作が多い人

エクセル、Photoshop、ブラウザで大量にスクロールする人にはタッチ方式の限界が早めに来る。慣れでカバーできる範囲には上限がある。

サイドボタンやショートカットを多用したい人

ボタン数の少なさはどのアプリを使っても増やせない。多ボタン派には最初から別の製品が適している。

Microsoft Arc Mouseを買って満足する人

毎日ノートPCを持ち歩くビジネスパーソン

移動中に荷物を増やしたくない人に向いている。スナップで接続が完了し、電池交換は半年に一度。出先で取り出して即使える設計は、Surface使いの口コミで特に繰り返し触れられていた。

見た目と携帯性を両立したい人

デザインと薄さを優先し、機能は最小限でいいという割り切りができる人には期待通りの満足感がある。

カフェや移動先でライトな作業をする人

メールの返信、資料の確認、軽いブラウジングを外出先でこなすなら、Arc Mouseは過不足ない選択だ。
